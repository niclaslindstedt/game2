Support

Write to niclas@agilator.se. Say which device you are on and what the game did; if it is about one stage, the seed on the pause card is enough to reproduce it exactly.

The game will not start

Building a stage takes a few seconds on a phone, and longer the first time. If it never gets past the loading screen, the usual cause is a browser with WebGL turned off or a very old graphics driver. On the web version, try reloading once — the game keeps a copy of itself for offline play, and a reload replaces a half-downloaded one.

Where my times and settings live

On your own device, in the browser's or the app's local storage. Nothing is on a server, so clearing site data or deleting the app deletes them, and there is no copy anywhere to restore. See the privacy policy.

Does it need the internet?

No. The mobile and desktop apps carry the whole game inside the download. The web version needs one visit to load, and plays offline afterwards.

A stage that is broken, or a corner that is not fair

Every stage is generated from a seed, so it can be rebuilt exactly. Send the seed and roughly where on the stage it happened, and it can be stood in front of and looked at.
