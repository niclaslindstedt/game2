# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating — in issues, discussions, pull requests, or any other project space — you agree to uphold it: be respectful, assume good faith, and keep the project a welcoming place for everyone.

## Reporting

Report unacceptable behavior through the private channel described in [SECURITY.md](SECURITY.md) — the same contact route handles conduct reports, so reports reach the maintainer without being public. Reports are handled confidentially.

## Enforcement

The maintainer reviews every report, responds to the reporter, and takes the action the Covenant's enforcement guidelines call for — from a private warning up to a permanent ban from project spaces.
