---
type: Added
title: A menu bar and a proper Dock icon on macOS
---

The desktop app now draws a real macOS menu bar — App, Race, Edit, View,
Window and Help — and every row presses a button the game already has:
restart, pause, main menu, take a photo, the gallery, settings and the
keyboard controls. Edit is the one that was quietly missing: without it
⌘C and ⌘V did nothing in the high-score board's name field.

The Dock icon is now drawn for macOS rather than reused from the web
install icon: the app mark masked to Apple's rounded-square, inset inside
its canvas, lit from above and sitting on its own shadow, at every size
from 16 to 1024.
