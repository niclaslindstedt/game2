type: Added
title: H puts the HUD away, and brings it back
---

The HUD now has a key of its own: press **H** on the road and the instruments
go, press it again and they come back. It is the same switch as OPTIONS ▸ HUD
and the HUD row on the pause card — not a separate one — so a HUD you turned
off mid-stage is still off on the next stage, and there is a row on screen
saying so rather than a game that looks broken.

That makes it the counterpart to holding ALT, which takes the chrome off only
for as long as the key is down: ALT is for one frame, H is for how you want to
play. Rebindable like every other key, on OPTIONS ▸ CONTROLS ▸ KEYBOARD.
