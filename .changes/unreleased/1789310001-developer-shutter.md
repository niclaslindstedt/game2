The shutter always answers. Pressing it while the HUD is hidden (ALT) now
still says PICTURE SAVED, a receipt no longer waits forever on a clipboard
that never replies, and a press with screenshots switched off says so
instead of doing nothing. A picture taken with the debug overlay up also
goes unsigned — the app's mark is there to say where a shared frame came
from, and a developer's frame is read for its boxes and its repro line,
which now runs the full width of the picture.
