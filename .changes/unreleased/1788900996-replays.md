title: Replays
---

Every run is now recorded as it is driven — not the pixels, the controls —
so the results card offers WATCH REPLAY: the same stage, the same car, the
same field and the same physics, driven again by the run you just did, and
opening on the TV cameras rather than the view you raced in. The camera key
still walks the whole ladder, so the corner that went wrong can be watched
from anywhere.

Nothing is kept unless you ask. Press the disk in the strip along the bottom
while a replay plays — the finish included — and it is filed; REPLAYS on the
main menu lists the last twelve, newest first, each one press from being on
the road again.
