type: Changed
title: The map's debug box is a copy button now
---

The developer map no longer prints what it knows down the side of the
landscape. The stage, the painted layer's reading, the framing and the REPRO
link are behind one button on the map's own strip — **COPY DEBUG INFO** — and
one press puts the lot on the clipboard as text, ready to paste into a report
or a prompt.

Two boxes and a wrapped URL used to cover the quarter of the island the
problem was usually in, and a number read off a screen still had to be typed
out by hand before anybody else could use it. The map gets its pixels back,
and the facts go where facts are actually wanted. A picture still carries the
full caption: **SCREENSHOT** paints the same boxes into the image it files.
