type: Fixed
title: A held pause button no longer flickers the pause card
---

On a controller, holding START opened the pause card and then closed it
again on the very next frame, over and over, so whether the game ended up
paused came down to when the thumb came off. Every button on the pad now
has to be released before it counts as a press again — including the one
that just handed the pad from the car to a menu, or from a menu back to
the car.
