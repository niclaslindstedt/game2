type: Changed
title: The camera key walks from the nose backwards
---

The eight driving views are now ordered from the nose of the car backwards —
BUMPER, HOOD, COCKPIT, then CLOSE, CHASE, FAR, HELI and TOP — instead of
starting behind the wheel. The camera key and the OPTIONS ▸ DRIVING row read
the same ladder, so a press still moves one rung; only which rung sits where
has changed. The view every stage opens in is still whatever you have chosen.
