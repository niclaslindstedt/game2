type: Fixed
title: ENTER takes a picture and nothing else — it no longer also presses the last button you clicked
---

Pressing ENTER mid-stage took the screenshot it is bound to AND threw the run
back to the last checkpoint. The keyboard was never the culprit: R is BACK TO
TRACK, B is RESTART STAGE and ENTER is SCREENSHOT, and each still is. The
second action came from the browser. A mouse press focuses the button it lands
on, so a driver who reached for the HUD's way back to the road with the mouse
left the keyboard aimed at that button for the rest of the stage — and ENTER's
default, for a key the page has left it, is to press whatever has focus.

A bound key is now spent where the game reads it and goes no further, so the
same press can never do two things. Two exceptions, and both are somebody
else's key: while a CARD is on screen the keyboard belongs to the card, so
ENTER still presses the row its cursor is standing on; and a CHORD is still
the browser's, so ⌘R reloads and CTRL+C copies as they always did. ALT is not
a chord — it is the game's own modifier — so ALT+ENTER still takes the picture
with the chrome off.
