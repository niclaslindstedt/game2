type: Changed
title: The phone and desktop apps no longer link to the source
---

The App Store and desktop builds carry no link back to the source code or
to the web edition: the main menu's version stamp is plain text there, the
bundled support page drops its "Source code" link, and the desktop Help
menu's Website, Privacy Policy and Support rows open the game's page on
apps.agilator.se. The store listings name the same pages. The website keeps
every link it had.
