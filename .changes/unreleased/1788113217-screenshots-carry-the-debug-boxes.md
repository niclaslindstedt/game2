type: Added
title: Screenshots go on the clipboard, and carry the debug boxes
---

Every picture now lands on the clipboard as it is filed in the gallery, so a
shot is one paste away from a chat window — Options ▸ Controls ▸ COPY TO
CLIPBOARD switches it off. With the debug overlay up, the shot carries the
overlay with it: the stage, the place, the camera and the REPRO line are
painted into the pixels, the way the developer map's screenshot already did
it. And god mode flown with the overlay OFF grows a COPY DEBUG INFO button,
so the numbers behind a frame can be lifted as text without putting four
panels over the thing being looked at.
