---
type: Changed
title: A new build is offered by a button, not a card
---

The card that announced a waiting build — a heading, a version line, a
RESTART and a dismiss, floating across the foot of the screen over the menu
and over a run alike — is now a single mark in the bottom-right corner. It
takes two presses: the first turns the mark into the word RESTART, the
second reloads into the new build, so a thumb that brushes it mid-stage
costs nothing and the button goes quiet again on its own. There is no longer
anything to dismiss, because there is no longer anything in the way.
