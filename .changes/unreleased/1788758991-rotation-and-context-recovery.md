type: Fixed
title: Rotating a phone no longer leaves a blank blue screen
---

Rotating the screen — especially rotating it in another app and then coming
back — could leave the game as a flat blue screen for several seconds. The
phone reclaims the graphics from an app in the background, and nothing noticed
when it did. The game now spots it, holds the run on the pause card behind a
LOADING screen instead of driving on behind a picture nobody can see, and comes
back the moment the graphics do. A rotation while the game is still loading is
picked up too, rather than being ignored until the first stage is standing.
