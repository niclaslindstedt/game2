---
type: Changed
title: The touch handbrake is called the handbrake
---

The hint arrow beside the thumb now reads HANDBRAKE rather than DRIFT, so
the gesture is named the same on the pedal ring as it is on the settings
page that rebinds it.

The ring reads the same way in every direction now, too: the arrow sits
between the thumb and the word it names, so BRAKE is below its arrow
rather than above it.
