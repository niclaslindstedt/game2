type: Added
title: START is NEXT on a controller
---

Every menu now opens with the cursor on the press you probably came for —
CAMPAIGN on the front door, the stage you are up to on a ladder, the car
itself on the pre-race card, RESUME on the pause card — and the pad's START
takes each screen's own way on, so holding it from the front door lands you
on a start line without a single choice made.
