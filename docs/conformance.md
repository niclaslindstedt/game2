# Conformance

Scandinavian Flick is built to the fleet's game guidelines, and `AGENTS.md`
names the version it follows. This page is the ledger of where the repository
**knowingly falls short** of them: one row per rule, the verdict, the evidence,
and what closing the gap would cost. A rule this page does not name is one the
repository meets; a gap found and not written down here is a bug in this page.

**Verdicts:** ◐ partial, with the gap named · ✗ not met · ⊘ a deliberate
deviation, by owner decision.

A row with no date behind it is an opinion, so every row carries the day it
was last checked against the tree. The closing step of a `maintenance` sweep
walks this table: re-check each row, re-date the ones that still hold, delete
the ones the tree has closed.

| Rule  | Subject                           |  V  | Evidence, and what closing it costs                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Checked    |
| ----- | --------------------------------- | :-: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| G3.14 | The developer toolbelt            |  ✗  | Every tool is reachable by one documented Make target and the measuring ones print their inputs, but **most do not answer `--help` and ignore an unknown flag**: `scripts/simulate-run.mjs` and `scripts/rate-stage.mjs` exit 0 on `--bogus-flag`, so a mistyped `--sedes 42` measures the default seeds and reports a confident wrong number. Closing it: one shared argument parser in `scripts/lib/`, adopted by thirty tools.                                                                                                                                  | 2026-09-28 |
| G3.15 | Worked examples                   |  ◐  | `examples/` holds a seed list and a machine-readable sim dump, both reproducible by one command. Nobody builds against the game (there is no mod format), so the directory is reference material rather than an example; no example is its own directory, and CI does not exercise them. Closing it: fold the two files into `docs/` and drop `examples/`.                                                                                                                                                                                                         | 2026-09-28 |
| G4.7  | One command per capability        |  ◐  | `make sim`, `make screenshots` and `make icons` exist. There is no `make bench` (see G10.5), and the assets target is spelled `make icons` and covers only the app mark — the preview and lab renders have no umbrella.                                                                                                                                                                                                                                                                                                                                            | 2026-09-28 |
| G6.6  | Slots never share storage         |  ◐  | The manifest's `id`/`scope`/`start_url`/`name` and the service worker's cache id branch per slot. **`localStorage` does not**: it is keyed by origin, so `/preview/` and `/` read and write the same boards, ghosts and settings. Closing it lands with G13.1's prefix move.                                                                                                                                                                                                                                                                                       | 2026-09-28 |
| G7.5  | The sequel test                   |  ◐  | The engine is content-free in its structure, but the rule suite is not: rule tests name shipped car ids (`createGame({ carId: "classic" })` throughout `drift_test`, `car_stats_test`, …), so deleting the catalog would redden hundreds of engine tests for content reasons. Closing it: a fixture registration seam the rule suite uses instead of shipped ids.                                                                                                                                                                                                  | 2026-09-28 |
| G7.6  | A narrow startup path             |  ◐  | The renderer is reached through a dynamic import, but the menu's backdrop IS the running game (`App.tsx` steps the engine under the drone camera), so the simulation is first-render code here by design.                                                                                                                                                                                                                                                                                                                                                          | 2026-09-28 |
| G8.1  | Catalogs as data                  |  ⊘  | **By owner decision.** Stages are generated from a seed rather than authored, so the only catalogs are `engine/game/defs/{cars,traffic,tuning}.ts` — TypeScript consts, not schema-validated data with a compile step. Nothing dangles today (the compiler resolves the references a schema would). Lost: retuning without a build, and a named schema a mod seam could stand on. Converting is a multi-week programme that only pays for itself alongside mod support.                                                                                            | 2026-09-28 |
| G8.3  | One identity module               |  ◐  | `pwa/src/identity.ts` holds the name, copy, colours and URLs, and every restatement is held to it by `tests/identity_test.ts` and `tests/tauri_test.ts`. **The storage prefixes are not in it**: `"scandi-flick-options"`, `"scandi-flick-scores:"` and a dozen more are literals in the modules that use them.                                                                                                                                                                                                                                                    | 2026-09-28 |
| G8.4  | Ids outlive their content         |  ◐  | Car and level ids are stable, already reach saves (`scandi-flick-scores:<levelId>`, the ghost per level, the chosen car in settings) and none has been reused. There is no tombstone list and no loader that could answer one, so retiring an id today would silently reinterpret every save that names it.                                                                                                                                                                                                                                                        | 2026-09-28 |
| G10.2 | The headless simulator            |  ◐  | `make sim` runs the real engine over scenarios and a whole roster, takes and prints seeds, probes generator dials without a rebuild, and runs in CI. Missing: **A/B comparison of two configurations** in one run, and a pass/warn/fail **verdict** against stated targets.                                                                                                                                                                                                                                                                                        | 2026-09-28 |
| G10.5 | Benchmarks against a baseline     |  ◐  | Frame cost in the real build is covered twice (`make profile`, and the in-game benchmark for the player's own machine). There is **no simulation-throughput benchmark**: nothing records steps per second on a fixed scenario, so an engine change that halves headless speed passes every gate.                                                                                                                                                                                                                                                                   | 2026-09-28 |
| G11.3 | Interface as content              |  ✗  | The HUD and menus are Preact components, not authored content with a schema and stable ids. With no mod boundary the interface is not required to be content; moving an instrument still means editing shell source.                                                                                                                                                                                                                                                                                                                                               | 2026-09-28 |
| G11.4 | Audio is content                  |  ◐  | Every sound is authored parameters (`lib/voice.ts`) routed once (`audio/route.ts`) over one bank. The cue/event split holds in practice, but the rate limit lives at the callers rather than in one funnel.                                                                                                                                                                                                                                                                                                                                                        | 2026-09-28 |
| G11.6 | Naming rules, written down        |  ◐  | The rule is right and followed — `car-creation` requires a period-idiom spec that never names the car it is drawn from — but it lives in a skill rather than `docs/naming.md`, and it covers the NAME only, not the voice, the art or the description a rename has to move with it.                                                                                                                                                                                                                                                                                | 2026-09-28 |
| G12.1 | Reference device and frame rate   |  ◐  | `pwa/src/game/device-gpu.ts` bands real devices by published scores and the in-game benchmark measures the machine in hand — the instruments exist. No document names the phone the game must hold 60 on.                                                                                                                                                                                                                                                                                                                                                          | 2026-09-28 |
| G12.4 | Accessibility                     |  ◐  | Reduced motion is honoured; input is broad (touch, pad, keyboard, remappable). **Not audited: colour-only state** — the damage schematic and the split boards lean on hue, and nothing checks that a second channel carries the same fact.                                                                                                                                                                                                                                                                                                                         | 2026-09-28 |
| G13.1 | Versioned saves                   |  ✗  | Progress (settings, boards, ghosts, split records, odometer, benchmark history, photos) is written to `localStorage` as bare JSON with **no version field on any structure** and no migration path. The cloud copy is versioned; the local stores it merges are not. A shape change silently drops or half-reads a player's history. Closing it: a version per persisted structure, a read that fails visibly, the prefixes moved into `identity.ts` and branched per slot. This is the one gap on the page that can cost a player something they cannot get back. | 2026-09-28 |
| G13.2 | Migration fixtures                |  ✗  | Follows from G13.1: with no versions there is nothing to migrate and no fixtures captured from shipped builds.                                                                                                                                                                                                                                                                                                                                                                                                                                                     | 2026-09-28 |
| G14.4 | The day boundary                  |  ◐  | The engine reads no clock. `dailySeed()` in the app reads the device's local date and nothing states which clock a day belongs to, so two players either side of midnight disagree about today's stage. Nothing competitive rides on it.                                                                                                                                                                                                                                                                                                                           | 2026-09-28 |
| G14.5 | A rule error ends the run visibly |  ◐  | The overlay's `[STAGE] … [REPRO]` block is a pasteable repro. Not established: what a thrown rule error does to a run in progress.                                                                                                                                                                                                                                                                                                                                                                                                                                 | 2026-09-28 |
| G14.8 | Text as a keyed catalog           |  ✗  | Every user-visible string is a literal in `pwa/src/`: English only, no keys, no template layer. The cost is not felt today and is the kind that is only ever felt all at once.                                                                                                                                                                                                                                                                                                                                                                                     | 2026-09-28 |
| G15.5 | Dependency licences               |  ◐  | `provenance.json` lists every shipped asset, and `make check-licenses` (CI's lint job) holds every npm package in the three lockfiles to an allow-list. **The desktop app's Rust crates are not checked**: `Cargo.lock` records no licence, so covering them needs `cargo metadata` (or a `cargo-deny` step) in the desktop workflow.                                                                                                                                                                                                                              | 2026-09-28 |
