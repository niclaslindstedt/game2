# The models

Every kind of object the game draws, and where what the player sees comes from: a **Blender** model (made off the game's own data by `make models`, committed in `pwa/models/`, drawn by every build — the `blender-assets` skill) or **code** (built by the game at run time). A modelled asset keeps its code builder: it is what the model is judged against, and a build switched back (`VITE_MODEL_*=0`, in the environment, the root `.env`, or `make ci-models MODELS=off` for CI) draws it instead. A modelled car is poured INTO the code-built car rather than drawn beside it, so the damage acts on the model's own meshes.

The road, the terrain and its water, the sky and the weather, the dust, the spray, the tyre tracks and the snow's marks are surfaces and effects rather than objects, and are always code.

The table is generated from `pwa/src/game/model-registry.ts` by `make model-registry` and never hand-edited; `tests/model_registry_test.ts` holds it, and holds the registry's Blender rows to exactly the files the build packs. **Modelling a new kind** is a row flipped from `code` to `blender` there, in the same change that ships its models.
